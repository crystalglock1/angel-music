# Angel — MVP

Мобильное музыкальное веб-приложение / Telegram Mini App. Стек: HTML, CSS и vanilla JavaScript без сборщика.

## Что работает

- Главная страница в стилистике утверждённых макетов.
- Поиск треков через Audius API (публичный read-only API).
- Поиск альбомов и исполнителей через MusicBrainz.
- Создание и удаление пользовательских плейлистов.
- Добавление и удаление треков из «Любимого» через меню трека.
- Добавление треков в пользовательские плейлисты через меню трека.
- Воспроизведение Audius-треков одним HTMLAudioElement, очередь, следующий/предыдущий, перемешивание коллекции.
- Локальное сохранение библиотеки в localStorage.
- Скачивание Audius-трека только при наличии флага `is_downloadable`, отсутствии download gate и непустом поле лицензии в ответе API.
- Telegram WebApp SDK: ready, expand и цвета шапки/фона.

## Важные ограничения

- MusicBrainz — каталог метаданных, а не музыкальный хостинг. Результаты альбомов и исполнителей открываются на MusicBrainz; наличие версии для прослушивания в Audius нужно искать отдельно.
- Audius — пользовательский каталог. `is_streamable` используется для потокового воспроизведения; скачивание показывается только при положительном флаге `is_downloadable`, отсутствии download gate и указанной лицензии. Это техническая проверка полей API, а не юридическая экспертиза прав на каждый трек.
- Jamendo пока не подключён: для него нужен собственный developer `client_id`. Не используется тестовый ключ из документации.
- Плейлисты и избранное хранятся только в localStorage текущего браузера/устройства. Облачной синхронизации нет.
- `BOT_TOKEN` не используется в браузере. Для команд бота, проверки подписи Telegram `initData`, серверной авторизации и облачной синхронизации понадобится backend. Не доверяй `initDataUnsafe` как подтверждённой личности.
- MusicBrainz просит не превышать один запрос в секунду на клиентское приложение; поиск задержан на 450 мс, но для публичного масштабирования нужен серверный прокси с общим rate limit и корректным User-Agent.

## Локальный запуск

Из папки проекта:

```bash
python3 -m http.server 8080
```

Открой `http://localhost:8080`. Не открывай `index.html` напрямую через `file://`: браузерные API и запросы к каталогам корректнее работают через HTTP.

## Telegram Mini App

1. Опубликуй статические файлы на HTTPS-хостинге (например, Vercel).
2. В BotFather укажи публичный HTTPS URL как Web App URL / Menu Button URL.
3. В `.env` локально укажи `APP_URL` и токен бота. Этот статический MVP не читает `.env`; переменные нужны для будущего backend/бота.
4. Не помещай `BOT_TOKEN` в публичные переменные фронтенда или репозиторий.

## Проверка

- Поиск: введи запрос, переключи «Треки / Альбомы / Исполнители».
- Плейлисты: «Ваши плейлисты» → «+» → создай список.
- Добавление: найди Audius-трек → «···» → выбери действие.
- Любимое: открой карточку «Любимое», проверь добавление/удаление.
- Воспроизведение: нажми ▶ у Audius-трека.
- Сохранение: обнови страницу и проверь библиотеку.

## Публикация на Vercel

Можно импортировать папку/репозиторий как Static Site. Build Command не нужен; Output Directory — `.`. Убедись, что `.env` исключён через `.gitignore`. Для текущей статической версии никакие секреты в Environment Variables не требуются.
